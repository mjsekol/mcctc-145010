## D2 · Screen reader

**Before you start:** headphones on, volume low. Wipe shared headphones before and after, or use your
own earbuds. The room stays quiet because thirty screen readers at speaker volume make everyone's
test useless.

**Windows Narrator.** Ctrl + Windows key + Enter starts and stops it. The Narrator key is Caps Lock
or Insert. Your instructor confirms the keys below on a lab machine before this lab.

| # | Check | Pass or fail | What you heard, word for word where you can |
|---|---|---|---|
| S1 | Page title announced when the page loads | | |
| S2 | Move by heading. Every heading is announced with its level, and the levels make an outline | | |
| S3 | Move by landmark. You hear header or banner, navigation, main, and footer or content info | | |
| S4 | The Spanish sentence is read with Spanish pronunciation | | |
| S5 | The table: each cell is read with its column name when you move across a row | | |
| S6 | Every form field is announced with its label, and required fields say required | | |
| S7 | The Yes and No choices are announced with the question | | |
| S8 | The map image is announced with alt text that tells you where the side door is | | |
| S9 | The logo and the calendar icon are not announced as separate images | | |
| S10 | Every link, heard alone, tells you where it goes | | |

**Moving by heading and landmark in Narrator.** Scan mode is toggled with Narrator + Space bar. In
scan mode, H moves to the next heading and D to the next landmark. **[VERIFY]** these on your lab
machine; your instructor will tell you if they differ.

**NVDA, if installed.** Insert + Down arrow reads from the cursor. H and D move by heading and
landmark in browse mode. Insert + F7 opens a list of links, headings, and landmarks. **[VERIFY]**
every NVDA key on the lab machine before relying on it.

### The recording

Record your screen, with the screen reader's speech, while you do S1, S2, S3, S6, and S10.
Two to four minutes is enough.

- Record the browser window only. No faces, no names on screen, no other tabs.
- Do not upload the recording to any AI tool, for any reason.
- Do not commit the video file to your repository. Video bloats Git history for everyone who ever
  clones it. Submit it where your instructor tells you, and write the file name here: ___________
- If recording is blocked on your machine, your partner writes a listening log instead: a
  timestamped list of what the screen reader said. Say which you did.
